# Liftron ARD — Elevator Safety Static Website

## Problem
Build a complete professional static business website (HTML/CSS/JS only, no React, no backend) for a company dealing in ARD (Automatic Rescue Device), Lift UPS Systems & Elevator Safety Solutions. Corporate industrial design inspired by Amerson India but not copied. Delhi NCR focus.

## Stack
Pure HTML5 + CSS3 + Vanilla JS. No framework, no build step. Deployable by opening index.html or uploading anywhere.
